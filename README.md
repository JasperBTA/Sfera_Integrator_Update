# Sfera Integrator (Release & Auto-Update Repository)

> **Note:** This is the public auto-update manifest (`update.xml`) and MSI distribution repository for **Sfera Integrator**. The application source code is maintained privately as an internal commercial tool; packaged installers are distributed via [Releases](../../releases).

## Overview

Integration service bridging **WordPress REST API** with **InsERT Gratyfikant GT** ERP/HR software. It automates employee onboarding by fetching submitted application records, validating payloads, and populating HR ledgers via the **InsERT Sfera COM API**.

## Tech Stack

- **Language / Runtime:** C# / .NET (Windows)
- **Integrations:** WordPress REST API, InsERT Sfera COM API (Gratyfikant GT)
- **Distribution:** MSI installer packages + XML auto-update manifest (`update.xml`)
